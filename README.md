# Vivarium Guide

An interactive guide to the process-bigraph / Vivarium 2.0 software ecosystem — the
formalism, the engine, studies & investigations, the Spatio-Flux worked example,
an embedded bigraph-loom renderer, and a searchable catalog of every wrapped simulator.

**Live:** https://vivarium-collective.github.io/vivarium-guide/

Two static files, no build step:
- `index.html` — the guide
- `loom.html` — the standalone bigraph-loom explorer embedded by the "Rendered by loom" section

Keep both files together.
